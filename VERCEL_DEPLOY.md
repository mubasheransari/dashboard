# Vercel deployment checklist

- [ ] Confirm the data is approved for cloud hosting.
- [ ] Create the three normalized Google Sheets tabs exactly as documented in README.md.
- [ ] Share the spreadsheet with the service account email as Viewer only.
- [ ] Push code to a private GitHub repository.
- [ ] Import the repository in Vercel.
- [ ] Add the three server-side environment variables.
- [ ] Deploy and confirm the source label says Google Sheets.
- [ ] Test Refresh data, date filters, monthly trend, and mobile layout.
- [ ] Confirm the Vercel plan is permitted for the intended company use.
